# Fase 2 · Power BI, DAX e storytelling

> 📍 Você está em: [início](../README.md) › **Fase 2 · Power BI, DAX e storytelling**

| | |
|---|---|
| **Duração estimada** | 1 a 2 meses |
| **Objetivo** | Transformar dados em painéis que gestores usam para decidir, e contar a história por trás dos números. |
| **Por que esta fase existe** | Power BI é a ferramenta de BI mais pedida no Brasil. Storytelling é o que faz sua análise ser ouvida. |
| **Entrega final** | Um painel publicado (Power BI) com modelo de dados em estrela, medidas DAX e uma página de "conclusões". |
| **Com o que se conecta** | Usa o SQL e o Excel/Power Query da Fase 1. Os painéis viram peças do portfólio. |

📚 **Onde estudar, certificado e projeto de portfólio desta fase:** ver o [Guia de estudo](../recursos/GUIA-DE-ESTUDO.md).
