## 1. O que é?
Linguagem de fórmulas do Power BI: medidas, CALCULATE, contexto de filtro, inteligência de tempo.

## 2. Por que estou estudando isso?
É o que permite indicadores como "vendas do mesmo mês do ano passado".

## 3. Quando usar (e quando NÃO usar)?
Cálculos que mudam conforme o filtro do usuário. NÃO use DAX para limpar dados (isso é Power Query ou SQL).

## 4. Com o que se conecta?
Equivale às agregações do SQL, mas dinâmicas.
