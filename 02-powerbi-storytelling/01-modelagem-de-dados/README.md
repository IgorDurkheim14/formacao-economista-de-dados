## 1. O que é?
Organizar tabelas em fatos (eventos, vendas) e dimensões (cliente, produto, data).

## 2. Por que estou estudando isso?
Um modelo bem feito deixa o painel rápido e as fórmulas simples.

## 3. Quando usar (e quando NÃO usar)?
Antes de qualquer painel com mais de uma tabela.

## 4. Com o que se conecta?
Usa o raciocínio de JOIN do SQL (Fase 1).
