## 1. O que é?
Biblioteca para tabelas: ler CSV/Excel/SQL, filtrar, agrupar, juntar, tratar datas e valores faltantes.

## 2. Por que estou estudando isso?
É o "Excel programável": o que você fez uma vez, roda de novo com um clique.

## 3. Quando usar (e quando NÃO usar)?
Limpeza e transformação repetitivas ou de bases médias/grandes.

## 4. Com o que se conecta?
Faz em código o que o SQL e o Power Query fazem (Fases 1 e 2).
