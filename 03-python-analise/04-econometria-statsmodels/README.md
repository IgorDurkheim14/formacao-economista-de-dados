## 1. O que é?
Regressão linear (MQO), erros robustos, dados em painel, testes de diagnóstico, interpretação de coeficientes.

## 2. Por que estou estudando isso?
É exatamente o que você já domina na teoria, agora na ferramenta que o mercado usa.

## 3. Quando usar (e quando NÃO usar)?
Quando a pergunta é "quanto X afeta Y?" e você precisa explicar, não só prever.

## 4. Com o que se conecta?
Ponte direta para inferência causal (Fase 4).
