# Modelos (templates)

> 📍 Você está em: [início](../README.md) › **Templates**

Arquivos para **copiar**, nunca para editar diretamente. Garantem que tudo no curso tenha o mesmo formato.

| Modelo | Quando usar | Para onde copiar |
|---|---|---|
| [`sessao-de-estudo.md`](sessao-de-estudo.md) | Ao fim de cada estudo | `progresso/diario/AAAA-MM-DD.md` |
| [`projeto-README.md`](projeto-README.md) | Ao começar um mini-projeto | `<fase>/<módulo>/projeto/README.md` |
| [`modulo-README.md`](modulo-README.md) | Se criar um módulo novo | `<fase>/<novo-módulo>/README.md` |
