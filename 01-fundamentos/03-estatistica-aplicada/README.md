## 1. O que é?
Média, mediana, dispersão, distribuições, intervalos de confiança, testes de hipótese, teste A/B, correlação x causalidade.

## 2. Por que estou estudando isso?
É o seu diferencial como economista: interpretar o número com rigor, sem conclusões apressadas.

## 3. Quando usar (e quando NÃO usar)?
Sempre que alguém perguntar "isso aumentou de verdade ou foi acaso?".

## 4. Com o que se conecta?
Base de econometria (Fase 3), ML e inferência causal (Fase 4).
