## 1. O que é?
Linguagem para consultar bancos de dados: SELECT, WHERE, GROUP BY, JOIN, subconsultas, funções de janela.

## 2. Por que estou estudando isso?
Quase toda empresa guarda dados em banco. Quem sabe SQL não depende de ninguém para pegar o dado.

## 3. Quando usar (e quando NÃO usar)?
Dados grandes, em banco, que precisam ser filtrados, cruzados ou agregados. NÃO precisa para uma tabela pequena que cabe numa planilha.

## 4. Com o que se conecta?
Alimenta Power BI (Fase 2) e pandas (Fase 3).
