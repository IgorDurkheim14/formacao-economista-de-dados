## 1. O que é?
Planilhas: PROCX/XLOOKUP, tabelas dinâmicas, Power Query, gráficos simples.

## 2. Por que estou estudando isso?
É a ferramenta que o negócio usa. Saber Excel bem faz você conversar com gestores na língua deles.

## 3. Quando usar (e quando NÃO usar)?
Análises rápidas, pontuais, para entregar a alguém que vai mexer na planilha. NÃO use para processos repetitivos com muitos dados (aí é SQL ou Python).

## 4. Com o que se conecta?
O Power Query do Excel é o mesmo do Power BI (Fase 2).
