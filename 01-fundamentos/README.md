# Fase 1 · Fundamentos: SQL, Excel e estatística aplicada

> 📍 Você está em: [início](../README.md) › **Fase 1 · Fundamentos: SQL, Excel e estatística aplicada**

| | |
|---|---|
| **Duração estimada** | 2 a 3 meses |
| **Objetivo** | Dominar o núcleo que aparece em praticamente todas as vagas de dados: buscar dados (SQL), organizar e calcular rápido (Excel) e interpretar com rigor (estatística). |
| **Por que esta fase existe** | É o que mais gera empregabilidade rápida. Com isso você já pode se candidatar a Analista de Dados Júnior/Pleno. |
| **Entrega final** | Um mini-projeto: perguntas de negócio respondidas com SQL sobre uma base pública, resumo em Excel e uma interpretação estatística em texto. |
| **Com o que se conecta** | O SQL vira a fonte de dados do Power BI (Fase 2) e do pandas (Fase 3). A estatística é a base da econometria e do ML (Fases 3 e 4). |

📚 **Onde estudar, certificado e projeto de portfólio desta fase:** ver o [Guia de estudo](../recursos/GUIA-DE-ESTUDO.md).
