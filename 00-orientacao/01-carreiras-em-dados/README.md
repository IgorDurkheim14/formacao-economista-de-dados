## Resumo das carreiras

| Carreira | Pergunta que responde | Ferramentas principais | Encaixe com você |
|---|---|---|---|
| Analista de Dados | O que aconteceu e por quê? | SQL, Excel, Power BI | Ótima porta de entrada |
| Analista de BI | Como acompanhar o negócio? | Power BI, DAX, SQL | Boa, mas usa pouco seu mestrado |
| Cientista de Dados | O que vai acontecer? | Python, ML, estatística | Alto |
| **Cientista de Dados Quantitativo / Economista de Dados** | **Qual o efeito de uma decisão? O que esperar?** | **Python, econometria, inferência causal, séries temporais** | **Máximo: seu alvo** |
| Engenheiro de Dados | Como os dados chegam limpos e no lugar certo? | SQL, Python, nuvem, pipelines | Baixo, exige mais tecnologia |
| Analytics Engineer | Como organizar os dados para análise? | SQL, dbt, modelagem | Médio |

> Estratégia: entrar pelo caminho de Analista de Dados (Fases 1 e 2) enquanto constrói o perfil de Economista de Dados (Fases 3 e 4).
