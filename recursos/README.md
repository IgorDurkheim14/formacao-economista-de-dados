## Bases de dados públicas (ótimas para projetos de economista)
| Fonte | O que tem | Link |
|---|---|---|
| IBGE (SIDRA) | PIB, população, PNAD, preços | https://sidra.ibge.gov.br |
| Banco Central (SGS) | Juros, câmbio, inflação, crédito | https://www3.bcb.gov.br/sgspub |
| IPEA Data | Séries macro e regionais | http://www.ipeadata.gov.br |
| Base dos Dados | Dados públicos brasileiros já tratados, via SQL (BigQuery) | https://basedosdados.org |
| Portal da Transparência | Gastos do governo federal | https://portaldatransparencia.gov.br |
| Kaggle | Bases variadas e competições | https://www.kaggle.com/datasets |
