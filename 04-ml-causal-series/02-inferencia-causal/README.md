## 1. O que é?
Experimentos (A/B), diferenças em diferenças, variáveis instrumentais, regressão descontínua, controle sintético, pareamento.

## 2. Por que estou estudando isso?
Responde "a ação X causou o resultado Y?". É onde economistas se destacam frente a outros cientistas de dados.

## 3. Quando usar (e quando NÃO usar)?
Avaliar políticas públicas, campanhas, mudanças de preço.

## 4. Com o que se conecta?
Evolução direta da econometria (Fase 3).
