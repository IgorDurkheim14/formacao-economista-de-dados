## 1. O que é?
Regressão e classificação, treino/teste, validação cruzada, árvores, random forest, gradient boosting, métricas.

## 2. Por que estou estudando isso?
Para prever: churn, inadimplência, demanda, preço.

## 3. Quando usar (e quando NÃO usar)?
Quando o objetivo é acertar a previsão. NÃO use ML quando uma média, regra simples ou regressão já resolve.

## 4. Com o que se conecta?
Usa pandas (Fase 3); o modelo pode virar app (Fase 5).
