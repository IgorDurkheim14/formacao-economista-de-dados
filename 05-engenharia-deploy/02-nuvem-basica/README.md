## 1. O que é?
Conceitos de nuvem (armazenamento, banco gerenciado, computação), BigQuery, Google Colab.

## 2. Por que estou estudando isso?
Empresas guardam dados na nuvem. Saber o básico evita travar na primeira semana de trabalho.

## 3. Quando usar (e quando NÃO usar)?
Quando os dados não cabem ou não estão no seu computador.

## 4. Com o que se conecta?
BigQuery usa SQL (Fase 1).
