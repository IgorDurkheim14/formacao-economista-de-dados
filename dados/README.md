# Dados

> 📍 Você está em: [início](../README.md) › **Dados**

**Por que existe:** separar os dados do código deixa claro de onde veio cada número.

| Pasta | O que vai | Regra |
|---|---|---|
| `brutos/` | Dados como vieram da fonte | **Nunca editar.** Se precisar mudar, gere uma versão em `tratados/`. |
| `tratados/` | Dados limpos, prontos para análise | Sempre anotar qual script/passo gerou o arquivo. |

## Regras importantes
- O GitHub não aceita arquivos acima de 100 MB, e acima de ~10 MB já fica pesado. Arquivos grandes vão para o Google Drive, com o link listado abaixo.
- Nunca salve aqui senhas, dados pessoais de clientes ou dados confidenciais de empresa.
