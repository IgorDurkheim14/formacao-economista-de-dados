# Glossário

> 📍 Você está em: [início](README.md) › **Glossário**

Termos em ordem alfabética, em português simples. Acrescente novos termos à medida que aparecerem.

| Termo | O que significa | Exemplo / quando aparece |
|---|---|---|
| **A/B (teste)** | Experimento comparando duas versões, com sorteio de quem vê cada uma. | Site com botão verde x azul. Fase 1 e 4. |
| **Analytics Engineer** | Profissional entre o analista e o engenheiro: organiza e modela os dados para análise (muito SQL e dbt). | Carreira, Fase 0. |
| **API** | Porta para um programa pedir dados a outro. | Baixar séries do Banco Central por Python. |
| **BI (Business Intelligence)** | Painéis e relatórios para acompanhar o negócio. | Power BI, Fase 2. |
| **Branch** | Uma "linha paralela" no Git para testar sem mexer na versão principal. | Fase 5. |
| **Clone** | Baixar um repositório inteiro para o seu computador (primeira vez). | `COMO-USAR.md`. |
| **Commit** | Uma "foto" salva das mudanças, com uma mensagem. | Ao fim de cada estudo. |
| **CSV** | Tabela em texto simples, colunas separadas por vírgula ou ponto e vírgula. | Base pública do IBGE. |
| **Dashboard** | Painel com indicadores e gráficos interativos. | Fase 2. |
| **DAX** | Linguagem de fórmulas do Power BI. | Fase 2. |
| **Deploy** | Publicar algo para que outras pessoas usem (um app, um modelo). | Streamlit, Fase 5. |
| **Diferenças em diferenças (DiD)** | Compara a mudança de um grupo afetado com a de um grupo não afetado. | Avaliação de política pública, Fase 4. |
| **ETL** | Extrair, Transformar e Carregar dados (o "encanamento"). | Power Query, pandas, SQL. |
| **Feature** | Uma variável usada por um modelo de ML. | Fase 4. |
| **Git / GitHub** | Git = programa que controla versões. GitHub = site que guarda repositórios Git na nuvem. | Este repositório. |
| **JOIN** | Juntar duas tabelas por uma coluna em comum. | SQL, Fase 1. |
| **Jupyter Notebook** | Arquivo (`.ipynb`) que mistura código, texto e gráficos. | Fase 3. |
| **Machine Learning (ML)** | Modelos que aprendem padrões para prever. | Fase 4. |
| **Markdown (`.md`)** | Texto simples com formatação leve. Todos os READMEs. | `COMO-USAR.md`. |
| **Modelo estrela** | Tabela fato no centro, tabelas de dimensão ao redor. | Power BI, Fase 2. |
| **Overfitting** | Modelo que "decorou" os dados de treino e erra em dados novos. | Fase 4. |
| **pandas** | Biblioteca Python para tabelas. | Fase 3. |
| **Power Query** | Ferramenta de limpar e transformar dados do Excel e do Power BI. | Fases 1 e 2. |
| **Pull / Push** | Pull = baixar as novidades do GitHub. Push = enviar suas mudanças ao GitHub. | Rotina de estudo. |
| **README** | Arquivo que explica uma pasta. O GitHub o mostra automaticamente. | Em toda pasta. |
| **Repositório (repo)** | Pasta de projeto controlada pelo Git. | Este. |
| **scikit-learn** | Biblioteca Python de ML. | Fase 4. |
| **SQL** | Linguagem para consultar bancos de dados. | Fase 1. |
| **statsmodels** | Biblioteca Python de estatística e econometria. | Fase 3. |
| **Streamlit** | Biblioteca que transforma script Python em app web. | Fase 5. |
| **Série temporal** | Dados medidos ao longo do tempo (mensal, diário...). | IPCA, PIB, vendas. Fase 4. |
